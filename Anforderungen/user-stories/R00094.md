# User Story R00094 — Durchläufe als Daten

Als Agent, der eine Phase für eine Karte abschließt,
möchte ich den Durchlauf strukturiert eintragen,
damit Phase, Ergebnis, Wer und Dauer später auswertbar sind.

## US-1: Durchlauf eintragen

- **Gegeben** die Aufgabe #97 ohne Durchläufe
- **Wenn** ich `POST /api/aufgaben/97/durchlaeufe {phase: Entwicklung, ergebnis: bestanden, dauer: 1:43, text: Gate grün}` sende
- **Dann** zeigt das Detail die Tabelle „Durchläufe“ mit dieser Zeile, und der Verlauf hat den Kommentar „Entwicklung bestanden (…, 1:43): Gate grün“

## US-2: Ungültiges Ergebnis

- **Gegeben** die Aufgabe #97
- **Wenn** ich `ergebnis: ok` sende
- **Dann** antwortet kanbanD `400` und nennt die erlaubten Werte
