# User Story R00044 — Burndown nach Zeitraum

Als Mensch, der den Fortschritt verfolgt,
möchte ich das Burndown auf einen Zeitraum und auf bestimmte Aufgaben beschränken,
damit ich genau den Abschnitt sehe, um den es geht.

## US-1: Zeitraum

- **Gegeben** ein Board mit Ständen vom 01. und 02.10.
- **Wenn** ich den Zeitraum 01.10.–01.10. wähle
- **Dann** zeigt das Burndown einen Tag mit zwei offenen Aufgaben
