# User Story R00086 — Zug ohne Index landet oben

Als Mensch, der einem Agenten zusieht,
möchte ich die zuletzt bewegte Karte oben in ihrer Spalte finden,
damit ich ohne Suchen sehe, was gerade passiert ist.

## US-1: Agent zieht ohne Index

- **Gegeben** die Spalte „Code-Review“ mit den Karten #5 und #6
- **Wenn** ein Agent #7 per API ohne Index nach „Code-Review“ zieht
- **Dann** steht #7 oben, darunter #5 und #6

## US-2: Ausdrücklicher Index gilt

- **Gegeben** dieselbe Spalte
- **Wenn** ein Agent #7 mit `index: 2` zieht
- **Dann** steht #7 an dritter Stelle
