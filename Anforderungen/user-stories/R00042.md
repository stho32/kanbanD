# User Story R00042 — Bewegungen eines Boards

Als Agent oder Bericht
möchte ich je Aufgabe wissen, wann sie in welche Spalte kam,
damit ich den Fluss eines Boards auswerten kann.

## US-1: Spaltenwechsel abfragen

- **Gegeben** ein Board mit drei Ständen in Git
- **Wenn** ich `GET /api/berichte/bewegungen?board=entwicklung` abrufe
- **Dann** steht je Aufgabe die Folge ihrer Spalten mit Zeitpunkt, „vom Board“ als `null`
