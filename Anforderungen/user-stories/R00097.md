# User Story R00097 — Spalten mit Eigentümer

Als Mensch, der Befunde freigibt,
möchte ich Spalten als „gehört dem Menschen“ markieren,
damit kein Agent eine Karte an meiner Freigabe vorbei in die Arbeit nimmt.

## US-1: Agent kann nicht an der Freigabe vorbei

- **Gegeben** der Eingang gehört dem Menschen und enthält #1
- **Wenn** ein Agent #1 über die API nach „Freigegeben“ bewegt
- **Dann** antwortet kanbanD mit 403, #1 liegt weiter im Eingang, und es entsteht kein Commit

## US-2: Agent liefert in eine Menschen-Spalte ab

- **Gegeben** „Verstehen & Freigabe“ gehört dem Menschen
- **Wenn** ein Behandler seine fertige Karte dorthin bewegt
- **Dann** liegt sie dort, und der Behandler kann sie danach nicht mehr herausbewegen

## US-3: Agent darf weiter kommentieren

- **Gegeben** #1 liegt im Eingang, der dem Menschen gehört
- **Wenn** ein Sensor #1 kommentiert, Zeit bucht und ein Signal setzt
- **Dann** gelingt alles, und #1 bleibt im Eingang

## US-4: Eigentümer einstellen

- **Gegeben** das Board mit der Spalte „Eingang“
- **Wenn** ich im Spalten-Dialog „Eigentümer: Mensch“ wähle und speichere
- **Dann** zeigt der Kopf von „Eingang“ das Mensch-Zeichen, und ich selbst kann Karten weiter frei bewegen
