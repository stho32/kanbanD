# User Story R00037 — Teilaufgaben schnell hintereinander

Als Mensch, der eine Aufgabe in Schritte zerlegt,
möchte ich Teilaufgaben ohne Wartezeit hintereinander eintippen,
damit ich im Denkfluss bleibe.

## US-1: Schnell tippen

- **Gegeben** das Fenster von #1 ist offen
- **Wenn** ich fünf Teilaufgaben ohne Pause eingebe, jeweils mit Enter
- **Dann** stehen alle fünf in meiner Reihenfolge an #1

## US-2: Live stört nicht

- **Gegeben** ich tippe gerade eine Teilaufgabe
- **Wenn** jemand anderes die Aufgabe ändert
- **Dann** bleibt mein angefangener Text im Feld
