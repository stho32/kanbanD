# User Story R00041 — Kürzel nach Kanbanflow-Konvention

Als Mensch, der von Kanbanflow kommt,
möchte ich die gewohnten Tasten nutzen,
damit ich ohne Umlernen schnell bin.

## US-1: Karte per Tastatur

- **Gegeben** #1 hat den Fokus
- **Wenn** ich die Leertaste drücke
- **Dann** läuft mein Timer auf #1; Entf archiviert #1

## US-2: Neue Aufgabe von überall

- **Gegeben** ich bin auf der Personen-Seite
- **Wenn** ich `n` drücke
- **Dann** öffnet sich „Neue Aufgabe“
