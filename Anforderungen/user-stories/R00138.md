# User Story R00138: Der gehaltene Fokus trifft nach einer fremden Listenänderung dasselbe Element

Als Mensch, der das Aufgabenfenster mit der Tastatur bedient,
möchte ich, dass der Fokus nach einer fremden Änderung an der Teilaufgaben- oder Herkunftsliste auf demselben Eintrag steht,
damit mein nächster Tastendruck nicht einen fremden Eintrag entfernt.

Gegeben in allen Szenarien: Aufgabe #1 im Aufgabenfenster, über die API herstellbar, mit Teilaufgaben „eins", „zwei", „drei" und (für US-3) mit zwei Herkünften. Ein Agent und ein Mensch sind bekannt. „Ein Agent entfernt über die API" heißt ein Schreibaufruf mit `X-KanbanD-Wer` eines Agenten, der die Liste ändert und ein Live-Ereignis auslöst. „Dasselbe Element" heißt: derselbe Teilaufgabentext bzw. derselbe Herkunftsverweis, auch wenn er nach der Änderung an einer anderen Stelle steht.

## US-1: Eine fremde Löschung nimmt mir nicht den Fokus von meiner Teilaufgabe

- **Gegeben** der Fokus steht auf dem ✕ von „Teilaufgabe zwei entfernen"
- **Wenn** ein Agent „Teilaufgabe eins" über die API entfernt (`DELETE /api/aufgaben/1/teilaufgaben/0`)
- **Dann** steht der Fokus nach dem Live-Ereignis (≤ 1 s) weiterhin auf dem ✕ derselben Teilaufgabe „zwei" (heute an Stelle 1) und **nicht** auf „Teilaufgabe drei entfernen"; ein anschließendes Enter entfernt „zwei", nie „drei".

## US-2: Bei doppeltem Inhalt fällt der Fokus auf den Abschnitt statt auf einen fremden Eintrag

- **Gegeben** #1 hat zwei gleich benannte Teilaufgaben „gleich", „gleich" und eine dritte; der Fokus steht auf dem ✕ einer der beiden
- **Wenn** ein Agent die andere „gleich" über die API entfernt
- **Dann** steht der Fokus auf dem Eingabefeld `#teil-neu`, **nie** auf dem ✕ der verbliebenen „gleich"; nichts Fremdes kann mit einem Tastendruck entfernt werden.

## US-3: Dasselbe gilt für die Herkunft

- **Gegeben** der Fokus steht auf dem ✕ einer Herkunft von #1
- **Wenn** ein Agent eine **andere** Herkunft über die API entfernt
- **Dann** steht der Fokus weiter auf dem ✕ derselben Herkunft; sind zwei Herkünfte gleich und ein Agent entfernt eine, steht der Fokus im Herkunftsfeld (`#herkunft-neu`), nie auf dem ✕ einer fremden Herkunft.

## US-4: Meine eigene Aktion bleibt unverändert

- **Gegeben** der Fokus steht auf dem ✕ von „Teilaufgabe zwei entfernen"
- **Wenn** ich selbst mit Enter „zwei" entferne
- **Dann** steht der Fokus auf dem ✕ des Nachbarn (der folgende rückt nach, am Ende der vorige) und, wenn keine Teilaufgabe mehr bleibt, auf `#teil-neu`; nach Strg+Z steht er auf dem ✕ von „zwei" wieder.
