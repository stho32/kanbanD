# User Story R00007 — Live-Aktualisierung

Als Mensch mit offenem Board
möchte ich Änderungen von Agenten, Editoren und anderen Browsern sofort sehen,
damit ich nie auf einem veralteten Stand arbeite.

## US-1: Editor ändert eine Aufgabe

- **Gegeben** das Board ist offen und zeigt #1 „eins“
- **Wenn** jemand in `aufgaben/0001-eins.md` den Titel auf „eins neu“ ändert
- **Dann** zeigt das Board ohne Neuladen „eins neu“, mit der Marke „extern“ an der Karte

## US-2: Agent verschiebt in der Board-Datei

- **Gegeben** das Board ist offen und #1 liegt in „Zu erledigen“
- **Wenn** ein Agent die Zeile von #1 in der Board-Datei unter „Erledigt“ setzt
- **Dann** steht #1 ohne Neuladen in „Erledigt“, mit der Marke „extern“

## US-3: Zweiter Browser

- **Gegeben** zwei Browser zeigen dasselbe Board
- **Wenn** im zweiten eine Karte angelegt wird
- **Dann** erscheint sie im ersten ohne Neuladen und ohne Marke
