# User Story R00242 — Laufansicht: Pfade als Links und kurze Pfad-Marken

Als Mensch, der eine Aufgabe in der Abnahme prüft,
möchte ich in der Laufansicht lange Pfade als kurze Marken ‹Projekt›, ‹Worktree #n› und ‹Ablage› lesen und gelesene oder geänderte Dateien mit einem Klick in VS Code an der richtigen Zeile öffnen,
damit ich sofort sehe, in welchem Ordner der Agent gearbeitet hat, und die Stelle prüfen kann, die er sah.

Ausgangslage jeder Story wie in R00242 „Ausgangslage“, herstellbar über die API: #1 trägt T14 (16 Einträge), #2 trägt T14o (3 Einträge), nur erfundene Inhalte. Mensch `sh`, Browser headless in `Europe/Berlin`. VS Code wird nicht geöffnet; geprüft wird das Ziel des Links.

## US-1: Kurze Pfade aus dem Kopf des Auftrags

- **Gegeben** die Laufansicht von T14
- **Wenn** `sh` den Auftrag (Nr 1) und den Schritt „Lesen“ (Nr 8) aufklappt
- **Dann** steht im Auftrag „Projekt: ‹demo›“, „Arbeitsort: Worktree ‹Worktree #7›“ und „Ablage: ‹Ablage›“. Der Befehl von Nr 8 lautet `cat ‹demo›/README.md &&` und ` ls ‹Worktree #7›/web`, ohne Link. Zeigt `sh` mit der Maus auf ‹demo›/README.md, steht der volle Pfad `/w/demo/README.md` als Tooltip da.

## US-2: Gelesene und geänderte Datei an der Zeile öffnen

- **Gegeben** die Laufansicht von T14
- **Wenn** `sh` die Schritte Read (Nr 2) und Edit (Nr 4) aufklappt
- **Dann** ist ‹Worktree #7›/web/a.js bei Read ein Link auf `vscode://file/w/wt/demo/karte-7/web/a.js:10`, und der Pfad bei Edit ist ein Link auf `vscode://file/w/wt/demo/karte-7/web/a%20b%3Fc%23d%25e%3A12.js:42`. Die Ergebnisse darunter zeigen ihre Pfade voll und ohne Link.

## US-3: Volle Ausgabe von Claude Code öffnen

- **Gegeben** die Laufansicht von T14
- **Wenn** `sh` den Schritt „Lesen“ (Nr 8) aufklappt
- **Dann** steht „Von Claude Code gekürzt (12,0 KB): Der Agent sah nur diese Vorschau. Vollständig: ‹Ablage›/tool-results/b1.txt“, und ‹Ablage›/tool-results/b1.txt ist ein Link auf `vscode://file/w/fab/ablage/plan-7/tool-results/b1.txt`. Die Vorschau „ok /w/demo/y.txt“ steht ohne Link.

## US-4: Pfade in einer Nachricht des Agenten

- **Gegeben** die Laufansicht von T14
- **Wenn** `sh` die Nachricht Nr 16 liest
- **Dann** sind `web/a.js` (als Code im Link), ‹demo›/src/b.rs:42, ‹demo›/a&b.js und /w/demox/c.rs Links. „cat web/a.js“ bleibt Code, „../x/y.js“ und der Pfad mit dem sichtbar gemachten Steuerzeichen ⟨U+202E⟩ bleiben ohne Link. Kopiert `sh` ‹demo›/src/b.rs:42, steht in der Zwischenablage `/w/demo/src/b.rs:42`.

## US-5: Ohne erkannten Kopf

- **Gegeben** die Laufansicht von T14o
- **Wenn** `sh` den Auftrag und den Read-Schritt aufklappt
- **Dann** steht keine Marke da. `/w/demo/a.js` steht voll und ist in beiden ein Link auf `vscode://file/w/demo/a.js`; „web/a.js“ bleibt Code ohne Link.
