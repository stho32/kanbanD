# User Story R00002 — Erster Start einrichten

Als Mensch, der kanbanD zum ersten Mal in einem Ordner startet,
möchte ich in einer Seite sagen, wer ich bin und wie mein erstes Board aussieht,
damit kanbanD eine versionierte Grundlage anlegt, ohne dass ich ein Dateiformat lerne.

## US-1: Einrichten

- **Gegeben** ein Ordner ohne `kanbanD.md`
- **Wenn** ich Kürzel `st`, Name „Stefan“, Board „Entwicklung“ und die Spalten „Zu erledigen, In Arbeit, Erledigt“ eingebe und „Einrichten und committen“ klicke
- **Dann** zeigt kanbanD das Board „Entwicklung“ mit drei Spalten, und der letzte Commit stammt von „Stefan“

## US-2: Vorschau

- **Gegeben** die Einrichtungsseite
- **Wenn** ich den Namen ändere
- **Dann** zeigt die Vorschau von `kanbanD.md` sofort den neuen Namen

## US-3: Unvollständige Angaben

- **Gegeben** die Einrichtungsseite
- **Wenn** ich ohne Kürzel absende
- **Dann** nennt die Seite den Fehler und legt keine Datei an
