# User Story R00024 — Agent arbeitet über die API

Als KI-Agent, der am Board mitarbeitet,
möchte ich alle Aktionen über eine beschriebene API ausführen,
damit ich ohne Oberfläche arbeiten kann und jede Aktion meinen Namen trägt.

## US-1: API finden

- **Gegeben** kanbanD läuft
- **Wenn** ich `/api/endpunkte` abrufe
- **Dann** bekomme ich alle Endpunkte mit Methode, Pfad, Identitätspflicht und Zweck

## US-2: Arbeiten unter eigenem Namen

- **Gegeben** ich bin der Agent `cl`
- **Wenn** ich eine Aufgabe anlege, meinen Timer starte, sie nach „Erledigt“ bewege, kommentiere und den Timer stoppe
- **Dann** stehen fünf Commits mit dem Autor „Claude“ in der Geschichte
