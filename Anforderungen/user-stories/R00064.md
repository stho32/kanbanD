# User Story R00064 — Zuständige per Dialog

Als Mensch, der Arbeit verteilt,
möchte ich die Zuständigen einer Karte in einem Dialog auswählen und gesammelt speichern,
damit die Karte ruhig bleibt und ich mehrere Mitglieder in einem Zug zuweise.

## US-1: Karte ohne mich-Knopf

- **Gegeben** Stefan ist für #1 zuständig
- **Wenn** ich auf die Karte zeige
- **Dann** sehe ich nur den Timer-Knopf, links neben Stefans Kürzel, das rechtsbündig unten auf der Karte steht

## US-2: Dialog aus dem Kartenmenü

- **Gegeben** Mia ist für #1 zuständig
- **Wenn** ich #1 rechts anklicke, „Zuständige zuweisen …“ wähle, Claude an- und Mia abhake und speichere
- **Dann** ist nur Claude zuständig; breche ich stattdessen ab, bleibt Mia zuständig

## US-3: Dialog per Taste

- **Gegeben** #1 hat den Fokus
- **Wenn** ich `p` drücke, mit Leertaste ein Mitglied umschalte und Enter drücke
- **Dann** ist die Auswahl gespeichert und #1 hat wieder den Fokus

## US-4: Dialog aus der Aufgabenliste

- **Gegeben** die Aufgabenliste zeigt #1
- **Wenn** ich die Zeile rechts anklicke, „Zuständige zuweisen …“ wähle, Claude anhake und speichere
- **Dann** ist Claude für #1 zuständig
