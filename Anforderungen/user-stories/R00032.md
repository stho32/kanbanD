# User Story R00032 — Sitzung und Verbindung

Als Mensch, der kanbanD den ganzen Tag offen hat,
möchte ich dort weitermachen, wo ich war, und sehen, ob alles live ist,
damit ich mich nicht jedes Mal neu orientieren muss.

## US-1: Letztes Board

- **Gegeben** ich habe zuletzt das Board „Test“ benutzt
- **Wenn** ich kanbanD neu öffne
- **Dann** ist „Test“ offen

## US-2: Timer im Tab

- **Gegeben** an einer Aufgabe läuft ein Timer
- **Wenn** ich auf die Tab-Leiste schaue
- **Dann** steht dort „(1 ▶) Entwicklung — kanbanD“

## US-3: Leeres Board erklärt sich

- **Gegeben** ein neues Board ohne Karten
- **Wenn** ich es öffne
- **Dann** erklärt die erste Spalte, wie Karten entstehen
