# User Story R00181 — Zeitkorrektur: Esc beendet nur die Korrektur, nicht das Fenster

Als Mensch, der im Aufgabenfenster mit der Tastatur eine Zeit korrigiert,
möchte ich, dass Esc nur die Korrektur beendet und das Fenster offen lässt,
damit ich nach einem Vertipper im Fenster weiterarbeite, statt die Aufgabe neu zu öffnen.

Herstellbar über die API: Aufgabe #1 mit einer beendeten Zeit (Beginn `2026-11-16 09:00`, Ende `2026-11-16 09:30`), Aufgabe #2 mit einer laufenden Zeit; Person `st` (Mensch) im Browser gewählt. „Nichts geschrieben“ heißt: kein `PATCH` an den Server, die Datei der Aufgabe unverändert, kein neuer Commit ([R00181](../R00181-behebung-zeitkorrektur-esc-beendet-nur-die-korrektur.md)).

## US-1: Esc beendet die Korrektur einer beendeten Zeit

- **Gegeben** das Aufgabenfenster von #1 in der Ansicht „Zeiten“, die Korrektur über den Stift (✎) geöffnet, „Beginn“ auf `2026-11-16 08:00` geändert
- **Wenn** ich Esc drücke
- **Dann** bleibt das Fenster offen, die Zeile zeigt wieder 09:00–09:30, der Fokus steht auf dem Stift dieser Zeile, und nichts ist geschrieben; drücke ich Esc ein zweites Mal, schließt das Fenster

## US-2: Esc beendet die Korrektur einer laufenden Zeit

- **Gegeben** das Aufgabenfenster von #2 in der Ansicht „Zeiten“, die Korrektur der laufenden Zeit geöffnet (nur „Beginn“), „Beginn“ geändert
- **Wenn** ich Esc drücke
- **Dann** bleibt das Fenster offen, die Zeile zeigt den Beginn aus der Datei und läuft weiter, der Fokus steht auf dem Stift dieser Zeile, und nichts ist geschrieben; ein zweites Esc schließt das Fenster

## US-3: Enter und ✓ speichern wie bisher

- **Gegeben** das Aufgabenfenster von #1 in der Ansicht „Zeiten“, die Korrektur geöffnet, „Beginn“ auf `2026-11-16 08:00` geändert
- **Wenn** ich Enter drücke (oder in einem zweiten Durchgang ✓ klicke)
- **Dann** ist die Korrektur gespeichert: die Zeile zeigt 08:00–09:30, das Fenster bleibt offen, und die Datei der Aufgabe trägt den neuen Beginn
