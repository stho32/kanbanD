# User Story R00066 — Teilaufgaben nachträglich bearbeiten

Als Mensch, der eine Aufgabe in Teilschritte zerlegt hat,
möchte ich den Text einer Teilaufgabe direkt ändern,
damit ich Formulierungen korrigiere, ohne die Teilaufgabe neu anzulegen.

## US-1: Text bearbeiten

- **Gegeben** das Aufgabenfenster zeigt die Teilaufgabe „Spalten lesn“
- **Wenn** ich auf den Text klicke, ihn zu „Spalten lesen“ korrigiere und Enter drücke
- **Dann** heißt die Teilaufgabe „Spalten lesen“ und ist weiterhin offen

## US-2: Verwerfen

- **Gegeben** ich bearbeite den Text einer Teilaufgabe
- **Wenn** ich Esc drücke
- **Dann** bleibt der alte Text, und das Aufgabenfenster bleibt offen

## US-3: Abhaken bleibt

- **Gegeben** eine offene Teilaufgabe
- **Wenn** ich auf ihr Kästchen klicke
- **Dann** ist sie abgehakt
