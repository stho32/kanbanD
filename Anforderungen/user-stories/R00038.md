# User Story R00038 — Erste offene Teilaufgabe auf der Karte

Als Mensch am Board
möchte ich den nächsten offenen Schritt jeder Aufgabe auf der Karte sehen und abhaken,
damit ich ohne Öffnen der Karte weiterkomme.

## US-1: Nächster Schritt

- **Gegeben** #1 hat „a“ erledigt, „b“ und „c“ offen
- **Wenn** ich das Board ansehe
- **Dann** steht unter dem Titel „☐ b“

## US-2: Direkt abhaken

- **Gegeben** die Karte zeigt „☐ b“
- **Wenn** ich auf das Kästchen klicke
- **Dann** ist „b“ erledigt und die Karte zeigt „☐ c“
