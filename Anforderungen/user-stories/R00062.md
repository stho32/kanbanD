# User Story R00062 — Leere Anwendungsliste löst die Bindung

Als Mensch mit mehreren Boards in einem Ordner,
möchte ich ein Board ausdrücklich von jeder Anwendung lösen,
damit kanbanD dort keine Phasen-Spalten anlegt.

## US-1: Board lösen

- **Gegeben** ein Ordner mit genau einer registrierten Anwendung und ein daran gebundenes Board „Abnahme“
- **Wenn** ich im Spalten-Dialog die Bindung auf „keine“ setze
- **Dann** ist „Abnahme“ ein reines Kanban, und beim nächsten Öffnen kommen keine Phasen-Spalten dazu

## US-2: Standard bleibt bequem

- **Gegeben** ein neues Board ohne Angabe zur Bindung und genau eine registrierte Anwendung
- **Wenn** ich es öffne
- **Dann** ist es an diese Anwendung gebunden und hat ihre Phasen-Spalten
