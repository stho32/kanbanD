# User Story R00080 — Auflösung im Fever Chart

Als Mensch, der ein Projekt wöchentlich oder monatlich steuert,
möchte ich die Bahn des Fever Charts in diesem Takt sehen,
damit die Richtung nicht im Rauschen von Tag zu Tag untergeht.

## US-1: Auflösung wählen

- **Gegeben** ein Fever Chart mit einem Punkt je Tag
- **Wenn** ich „Auflösung“ auf „Woche (alle 7 T)“ stelle
- **Dann** zeigt die Bahn nur jeden siebten Tag rückwärts vom letzten Stand, der letzte Stand bleibt, nichts wird neu gerechnet, und die Wahl steht in der Board-Datei
