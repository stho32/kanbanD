# User Story R00003 — Identität wählen

Als Mensch im Browser oder Agent an der API
möchte ich sagen, wer ich bin, ohne mich anzumelden,
damit jede Änderung meinen Namen trägt.

## US-1: Mensch wählt sich

- **Gegeben** ein eingerichteter Ordner mit dem Menschen „Stefan“ und dem Agenten „Claude“
- **Wenn** ich in der Kopfzeile „nicht gewählt“ öffne und „Stefan“ wähle
- **Dann** zeigt die Kopfzeile „Stefan“, auch nach dem Neuladen dieses Tabs

## US-2: Jeder Tab für sich

- **Gegeben** ich habe in einem Tab „Stefan“ gewählt
- **Wenn** ich kanbanD in einer neuen Sitzung öffne
- **Dann** zeigt die Kopfzeile „nicht gewählt“

## US-3: Agent nennt sich

- **Gegeben** der Agent „cl“ ist in `kanbanD.md` eingetragen
- **Wenn** er `GET /api/wer` mit `X-KanbanD-Wer: cl` aufruft
- **Dann** bekommt er seine Person zurück; ein unbekanntes Kürzel wird abgewiesen
