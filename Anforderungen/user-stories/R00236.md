# User Story R00236 — Review-Seite: Pfad kopieren, in VS Code öffnen und Patch je Datei

Als Mensch, der in der Abnahme die Commits einer Aufgabe prüft und am Rechner des Boards VS Code offen hat,
möchte ich aus der Review-Seite eine Datei in VS Code an der geänderten Zeile öffnen, ihren vollständigen Pfad kopieren und ihren Patch herunterladen,
damit ich eine Stelle im Editor weiterlese, ohne Pfad und Zeile abzutippen.

Ausgangslage jeder Story wie in R00236 „Ausgangslage“: Repository `W` = `<tmp>/R x`, im Register als Unterordner `W/plan`, Commits K-Pfad und K-Gross, Aufgabe #4 mit `kd` und `wb`; Mensch `sh`; Browser headless.

## US-1: An die erste hinzugefügte Zeile

- **Gegeben** die Review-Seite von K-Pfad
- **Wenn** `sh` an `src/a.rs` auf „VS Code“ zeigt und klickt
- **Dann** lautet der Tooltip „In VS Code an Zeile 13 öffnen“, und geöffnet wird `vscode://file<W kodiert>/src/a.rs:13`, nicht der Hunkanfang 10

## US-2: Jede Zeilennummer der neuen Seite springt

- **Gegeben** K-Pfad mit `src/a.rs` offen
- **Wenn** `sh` auf die Nummer 10 der neuen Seite klickt und danach auf die Nummer 13 der alten Seite
- **Dann** öffnet der erste Klick `…/src/a.rs:10`, und der zweite öffnet nichts

## US-3: Pfad in der Zwischenablage

- **Gegeben** K-Pfad, Board über `http://127.0.0.1`
- **Wenn** `sh` an `src/a.rs` „Pfad“ drückt
- **Dann** liegt `<W>/src/a.rs` in der Zwischenablage, unter dem Knopf steht „Pfad kopiert“ und wird angesagt, und die Nachbarknöpfe bleiben, wo sie waren

## US-4: Ohne Zwischenablage nicht still (Fehlerfall)

- **Gegeben** K-Pfad, Board von einem anderen Gerät über `http://<ip>:7422` (ohne `navigator.clipboard`)
- **Wenn** `sh` an `src/a.rs` „Pfad“ drückt
- **Dann** steht `<W>/src/a.rs` markiert in einem Feld mit „Pfad markiert — mit Strg + C kopieren“, und die Konsole bleibt leer

## US-5: Patch einer Datei, auch in „Alle Änderungen“

- **Gegeben** Aufgabe #4 auf „Alle Änderungen“
- **Wenn** `sh` im Abschnitt `wb` an `b.js` „Patch“ drückt
- **Dann** lädt der Browser `b.js.patch` mit dem Patch dieser Datei aus `wb` herunter, und „VS Code“ an `b.js` zeigt auf die Wurzel von `wb` mit Zeile 5

## US-6: Kein Link, der täuscht (Grenze)

- **Gegeben** K-Pfad
- **Wenn** `sh` die Köpfe von `weg.rs`, `bidi-‮datei.dat`, `neu.rs` und `a/b?c#d%e:12.rs` liest
- **Dann** tragen `weg.rs` und `bidi-‮datei.dat` nur „Pfad“ und „Patch“, `neu.rs` trägt „VS Code“ ohne Zeile mit „In VS Code öffnen“, und `a/b?c#d%e:12.rs` zeigt auf `…/a/b%3Fc%23d%25e%3A12.rs:1`

## US-7: Die Antwort kennt die Wurzel

- **Gegeben** K-Pfad, `repository` im Register ist `W/plan`
- **Wenn** ein Agent `GET /api/aufgaben/<nr>/diff` und `…?commit=<verweis>` liest
- **Dann** tragen beide Antworten `"wurzel": "<W>"`, und nach einer Änderung des Registers kommt kein 304 mit der alten Wurzel
