# User Story R00001 — Ordner öffnen

Als Mensch, der neben seiner Arbeit ein Kanban führen will,
möchte ich kanbanD mit einem Befehl für einen Ordner starten,
damit ich ohne Einrichtung sofort im Browser loslegen kann.

## US-1: Start in einem neuen Ordner

- **Gegeben** ein Pfad, unter dem noch kein Ordner liegt
- **Wenn** ich `kanbanD <pfad>` aufrufe
- **Dann** existiert der Ordner als Git-Repository, die Konsole nennt die Adresse und der Browser zeigt kanbanD

## US-2: Start in einem bestehenden Repository

- **Gegeben** ein Ordner in einem Git-Repository mit Commits
- **Wenn** ich `kanbanD <ordner>` aufrufe
- **Dann** bleiben die Commits unverändert und kanbanD zeigt den Ordner

## US-3: Belegter Port

- **Gegeben** Port 7420 ist belegt
- **Wenn** ich kanbanD starte
- **Dann** lauscht kanbanD auf dem nächsten freien Port und nennt ihn
