# User Story R00088 — Signal auffällig und „Signale oben“

Als Mensch, der einem KI-Lauf zusieht,
möchte ich Karten mit Signal sofort erkennen und auf Wunsch oben sehen,
damit ich reagiere, wo ich gebraucht werde.

## US-1: Karte trägt die Signalfarbe

- **Gegeben** eine Karte ohne Signal
- **Wenn** ein Agent das Signal „review“ setzt
- **Dann** bekommt die Karte live einen Streifen und Hintergrundton in der Farbe von „review“

## US-2: Signale oben

- **Gegeben** eine Spalte mit #1, #2 (Signal), #3, #4 (Signal)
- **Wenn** ich „Signale oben“ einschalte
- **Dann** zeigt die Spalte #2, #4, #1, #3, und nach dem Ausschalten wieder #1, #2, #3, #4

## US-3: Kein Umsortieren in der sortierten Ansicht

- **Gegeben** „Signale oben“ ist an
- **Wenn** ich eine Karte innerhalb der Spalte ziehe
- **Dann** bleibt die Reihenfolge, und ein Hinweis erklärt warum
