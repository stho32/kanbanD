# User Story R00077 — Responsive für Tablet und Handy

Als Mensch, der nicht am Schreibtisch sitzt,
möchte ich das Board auf Handy und Tablet bedienen können,
damit ich unterwegs nachsehen, verschieben und quittieren kann.

## US-1: Board auf dem Handy

- **Gegeben** ein Board mit drei Spalten, geöffnet auf einem Handy
- **Wenn** ich nach links wische
- **Dann** sehe ich Spalte für Spalte in voller Breite, ohne dass die Seite herausgezoomt ist

## US-2: Aufgabe auf dem Handy bearbeiten

- **Gegeben** dasselbe Board auf dem Handy
- **Wenn** ich eine Karte antippe
- **Dann** füllt das Aufgabenfenster den Bildschirm, die Felder stehen unter der Beschreibung, und über „Spalte“ verschiebe ich die Karte

## US-3: Tablet

- **Gegeben** das Board auf einem Tablet im Hochformat
- **Wenn** ich es öffne
- **Dann** steht der Filter in einer eigenen Zeile unter Navigation und Personenknopf, nichts überlappt
