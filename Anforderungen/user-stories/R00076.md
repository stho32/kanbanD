# User Story R00076 — Signale

Als Mensch, der mit Agenten am selben Board arbeitet,
möchte ich, dass Karten, die meine Aufmerksamkeit brauchen, ein auffälliges Signal tragen,
damit ich sie sofort sehe und mit einem Klick quittieren kann.

## US-1: Signal einrichten

- **Gegeben** „Einrichten“
- **Wenn** ich ein Signal „fragen“ mit der Bedeutung „Coding-Agent hat Fragen“ und der Farbe Violett anlege
- **Dann** steht es unter `signals:` in `kanbanD.md`

## US-2: Ein Agent setzt ein Signal, ich quittiere

- **Gegeben** das Signal „fragen“ ist eingerichtet, Karte #7 liegt auf dem Board
- **Wenn** ein Agent `PUT /api/aufgaben/7/signale/fragen` aufruft
- **Dann** pulsiert an #7 eine violette Fackel mit dem Tooltip „Coding-Agent hat Fragen“, der Spaltenkopf zeigt Fackel ×1; klicke ich auf die Fackel, ist das Signal weg

## US-3: Nach Signalen filtern

- **Gegeben** zwei Karten mit „fragen“, eine ohne
- **Wenn** ich im Spaltenkopf auf die Fackel klicke oder `signal:fragen` filtere
- **Dann** sehe ich nur die zwei Karten

## US-4: Fälligkeit als Signal

- **Gegeben** eine Karte mit Fälligkeit gestern und eine mit Fälligkeit heute
- **Wenn** ich das Board ansehe
- **Dann** trägt die erste ein rotes, die zweite ein bernsteinfarbenes Kalendersymbol; `signal:due` zeigt beide
