# User Story R00051 — Endpunkt „verlauf“ bleibt für Agenten

Als Agent, der den Fortschritt eines Boards meldet,
möchte ich offene Aufgaben je Tag und Durchlaufzeiten fertig gerechnet abrufen,
damit ich nicht selbst aus den Bewegungen rechnen muss.

## US-1: Abrufen

- **Gegeben** ein Board mit Geschichte in Git
- **Wenn** ich `GET /api/berichte/verlauf?board=entwicklung` abrufe
- **Dann** bekomme ich Tage, Durchläufe, Mittel und Median wie bisher
