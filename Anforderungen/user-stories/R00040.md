# User Story R00040 — Ziehen in der Aufgabenliste

Als Mensch, der Aufgaben einplant,
möchte ich Zeilen der Aufgabenliste auf Board-Spalten oder ins Archiv ziehen,
damit ich ohne Menü verteile.

## US-1: Auf ein Board ziehen

- **Gegeben** #2 liegt auf keinem Board
- **Wenn** ich die Zeile von #2 auf „Entwicklung · In Arbeit“ ziehe
- **Dann** liegt #2 auf dem Board in „In Arbeit“

## US-2: Ins Archiv ziehen

- **Gegeben** #1 ist offen
- **Wenn** ich die Zeile auf „Archiv“ ziehe
- **Dann** ist #1 archiviert
