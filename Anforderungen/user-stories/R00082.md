# User Story R00082 — Gewonnenen Puffer im Fever Chart beschriften

Als Mensch, der das Fever Chart liest,
möchte ich bei negativem Pufferverbrauch lesen, was er bedeutet,
damit ich einen richtigen Wert nicht für einen Fehler halte.

## US-1: Puffer gewonnen

- **Gegeben** ein Punkt unter 0 %, dessen Umfang kleiner war als heute
- **Wenn** ich mit dem Zeiger darüber fahre
- **Dann** steht dort „Puffer gewonnen: n Arbeitstage vor Planende“ und „Umfang damals …, heute …“; die Fläche unter 0 % heißt „vor Plan — Puffer gewonnen“
