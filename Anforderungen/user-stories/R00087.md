# User Story R00087 — Reservierungen und Ziehen

Als Betreiber einer Software Factory mit mehreren KI-Agenten
möchte ich, dass jeder Agent sich atomar die nächste Karte zieht und reserviert,
damit N Agenten ohne Doppelarbeit an einem Board arbeiten.

## US-1: Zwei Agenten ziehen gleichzeitig

- **Gegeben** die Spalte „Bereit“ mit den Karten #7 und #8 und zwei Agent-Instanzen derselben Rolle
- **Wenn** beide gleichzeitig aus „Bereit“ ziehen
- **Dann** bekommt die eine #7 und die andere #8, beide stehen oben in der Folgespalte und tragen je ein Schloss

## US-2: Nichts mehr zu ziehen

- **Gegeben** „Bereit“ enthält nur eine Karte, die eine andere Instanz reserviert hat
- **Wenn** ein Agent aus „Bereit“ zieht
- **Dann** antwortet kanbanD „nichts zu ziehen“, und keine Karte bewegt sich

## US-3: Reservierung im Detail freigeben

- **Gegeben** eine Karte mit Schloss, deren Agent abgestürzt ist
- **Wenn** ich die Aufgabe öffne und bei „Reservierung“ auf „freigeben“ klicke
- **Dann** verschwindet das Schloss, und der nächste Agent kann die Karte ziehen

## US-4: Alle Reservierungen zentral

- **Gegeben** ein Board mit drei reservierten Karten
- **Wenn** ich im Board-Menü „Alle Aufgabenreservierungen anzeigen“ wähle
- **Dann** sehe ich drei Zeilen mit Karte, Person, Instanz und Restzeit, und „alle freigeben“ entfernt alle drei Schlösser
