# User Story R00013 — Kommentieren

Als Mensch oder Agent, der an einer Aufgabe arbeitet,
möchte ich eine Bemerkung an der Aufgabe hinterlassen,
damit die Absprache dort steht, wo sie gebraucht wird.

## US-1: Mensch kommentiert

- **Gegeben** ich bin „Stefan“ und das Fenster von #1 ist offen
- **Wenn** ich „Gut so.“ eingebe und Enter drücke
- **Dann** steht der Kommentar mit „Stefan“ und der Uhrzeit im Fenster und in der Datei

## US-2: Agent kommentiert

- **Gegeben** der Agent „cl“
- **Wenn** er `POST /api/aufgaben/1/kommentare` mit einem zweizeiligen Text aufruft
- **Dann** steht der Kommentar mit „cl“ in der Datei, und der Commit trägt „Claude“
