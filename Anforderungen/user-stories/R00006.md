# User Story R00006 — Aufgabe bewegen

Als Mensch am Board
möchte ich eine Karte in eine andere Spalte ziehen,
damit das Board zeigt, wo die Arbeit steht — ohne dass sich die Aufgabe selbst ändert.

## US-1: In eine andere Spalte

- **Gegeben** Karte #1 liegt in „Zu erledigen“
- **Wenn** ich sie auf die freie Fläche von „In Arbeit“ ziehe
- **Dann** steht #1 in „In Arbeit“, der letzte Commit ändert nur die Board-Datei

## US-2: Umsortieren

- **Gegeben** „Zu erledigen“ enthält #1, #2, #3
- **Wenn** ich #3 auf die obere Hälfte von #1 ziehe
- **Dann** lautet die Reihenfolge #3, #1, #2

## US-3: Agent bewegt

- **Gegeben** der Agent „cl“ kennt die API
- **Wenn** er `POST /api/boards/entwicklung/bewegen` mit `{nummer: 2, spalte: "Erledigt"}` aufruft
- **Dann** liegt #2 in „Erledigt“ und der Commit trägt „Claude“
