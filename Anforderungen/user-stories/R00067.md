# User Story R00067 — Teilaufgaben per Ziehen ordnen

Als Mensch, der eine Aufgabe in Teilschritte zerlegt hat,
möchte ich die Teilaufgaben im Aufgabenfenster per Ziehen umordnen,
damit ihre Reihenfolge der geplanten Abfolge entspricht.

## US-1: Nach vorn ziehen

- **Gegeben** die Teilaufgaben a, b, c
- **Wenn** ich c auf die obere Hälfte von a ziehe
- **Dann** lautet die Reihenfolge c, a, b, auch in der Datei, und die Karte zeigt c als nächste offene Teilaufgabe

## US-2: Ans Ende ziehen

- **Gegeben** die Teilaufgaben a, b, c
- **Wenn** ich a auf die untere Hälfte von c ziehe
- **Dann** lautet die Reihenfolge b, c, a
