# User Story R00240 — Laufansicht: Einträge lesbar gesetzt

Als Mensch, der eine Aufgabe in der Abnahme prüft,
möchte ich in einem aufgeklappten Schritt den Aufruf in der Form seines Werkzeugs und ein Ergebnis mit hervorgehobener Testzeile sehen, und dabei jede Kürzung ihrem Urheber zuordnen können,
damit ich ohne durch rohes JSON und lange Ausgaben zu scrollen erkenne, was der Agent getan hat und was er davon zu sehen bekam.

Ausgangslage jeder Story wie in R00240 „Ausgangslage“, herstellbar über die API: #1 trägt T13 (17 Einträge, nur erfundene Inhalte). Mensch `sh`, Browser headless in `Europe/Berlin`. „Systemhinweise“ ist aus (Vorgabe aus R00239), wo nicht anders genannt.

## US-1: Befehl als Shell-Block, abgesetzt vom Ergebnis

- **Gegeben** die Laufansicht von T13
- **Wenn** `sh` den Schritt „Tests fahren“ (Nr 2) aufklappt
- **Dann** steht oben der Block „Aufruf“ mit eigener Fläche und Kante. Darin steht der Befehl in drei Zeilen: `cd /w/demo &&`, ` npm test;` und ` echo "a && b" | grep 'x;y' # Ende; z`, darunter „timeout: 120000“. Darunter steht „Ergebnis“ mit der hervorgehobenen Zeile „1 failed, 3 passed“ im Fehler-Ton, 20 Zeilen bis „Zeile 20“ und „weitere 5 Zeilen“.

## US-2: Edit als Diff, Write gekürzt

- **Gegeben** die Laufansicht von T13
- **Wenn** `sh` die Schritte Edit (Nr 6) und Write (Nr 8) aufklappt
- **Dann** zeigt Edit „x“, „− alt“, „+ neu“ und „y“. Write zeigt 20 Zeilen „+ b1“ bis „+ b20“ und „weitere 5 Zeilen“. Wählt `sh` „weitere 5 Zeilen“, stehen „+ b21“ bis „+ b25“ da.

## US-3: Gekürzte Ausgabe von Claude Code erkennen

- **Gegeben** die Laufansicht von T13
- **Wenn** `sh` die Zeile „Protokoll lesen“ (Nr 4) ansieht und aufklappt
- **Dann** steht schon zugeklappt „Von Claude Code gekürzt“ mit Symbol statt `<persisted-output>`, und die Zeile steht in der Fehlerform. Der Befehl endet nach 200 Zeichen mit einem gedämpften „…“ mit dem Tooltip „Von kanbanD gekürzt, vollständig im aufgeklappten Schritt“. Aufgeklappt steht „Von Claude Code gekürzt (69,9 KB): Der Agent sah nur diese Vorschau. Vollständig: /tmp/demo/tool-results/b1.txt“ und darunter die Vorschau mit „Exit code 1“. Der Kopf zeigt „Fehler erkannt“ 1.

## US-4: Systemhinweise mitten im Text eingeklappt

- **Gegeben** die Laufansicht von T13
- **Wenn** `sh` unter „Zeigen“ „Systemhinweise“ anhakt und den Edit-Schritt (Nr 6) aufklappt
- **Dann** steht im Ergebnis zwischen „Datei geändert.“ und „weiter“ ein eingeklapptes „Systemhinweis“. Unter „Bitte weiter.“ (Nr 12) steht ebenso eines. Die Read-Zeile (Nr 10) zeigt zugeklappt gedämpft „Systemhinweis“. Hakt `sh` „Systemhinweise“ wieder ab, sind die eingebetteten Hinweise weg, und „Datei geändert.“ und „weiter“ stehen weiter da.

## US-5: Längste Schritte nach ihrer Absicht

- **Gegeben** die Laufansicht von T13
- **Wenn** `sh` „Längste Schritte“ liest
- **Dann** stehen dort „Tests fahren“ (40 s) und „Protokoll lesen“ (30 s), je mit dem gekürzten Befehl gedämpft darunter, und „Write /w/demo/b.txt“ (20 s) ohne Absicht. Wählt `sh` „Tests fahren“, springt die Ansicht zu Nr 2.
