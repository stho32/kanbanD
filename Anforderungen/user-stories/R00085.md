# User Story R00085 — Live-Verbindung mit Herzschlag

Als Mensch, der einem Agenten auf dem Board zusieht,
möchte ich, dass die Sicht nach einem Verbindungsabriss von selbst wieder aktuell wird,
damit ich nicht neu laden muss, um zu sehen, was passiert.

## US-1: Stille Verbindung

- **Gegeben** ein offenes Board, dessen Live-Verbindung still abgerissen ist
- **Wenn** ein Agent eine Karte per API verschiebt
- **Dann** steht die Karte spätestens nach etwa 40 s in der neuen Spalte, und der Hinweis „Wieder verbunden · Stand nachgeladen“ erscheint

## US-2: Server neu gestartet

- **Gegeben** ein offenes Board
- **Wenn** kanbanD neu startet und ein Agent danach eine Karte anlegt
- **Dann** erscheint die Karte ohne Reload

## US-3: Tab wieder sichtbar

- **Gegeben** ein Tab, der lange im Hintergrund lag
- **Wenn** ich ihn wieder nach vorn hole
- **Dann** prüft er sofort die Verbindung und zeigt den aktuellen Stand
