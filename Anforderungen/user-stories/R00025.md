# User Story R00025 — Defekte Dateien zeigen

Als Mensch, der nach einem Merge weiterarbeitet,
möchte ich sehen, welche Dateien defekt sind,
damit ich sie gezielt repariere und nichts verloren geht.

## US-1: Defekte Aufgabe

- **Gegeben** `aufgaben/0002-zwei.md` enthält Konfliktmarker
- **Wenn** ich das Board öffne
- **Dann** steht dort „#2 — Datei defekt“ mit dem Fehler, und das Fenster zeigt die Datei nur zum Lesen

## US-2: Defektes Board

- **Gegeben** die Board-Datei ist unlesbar
- **Wenn** ich das Board öffne
- **Dann** sehe ich „boards/entwicklung.md ist defekt“ mit dem Fehler und einem Link zum Editor

## US-3: Reparatur

- **Gegeben** #2 ist als defekt markiert
- **Wenn** ich die Datei im Editor repariere
- **Dann** zeigt das Board #2 wieder normal, ohne Neuladen
