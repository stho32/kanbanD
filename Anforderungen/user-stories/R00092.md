# User Story R00092 — API aufräumen

Als Agent, der über die API arbeitet,
möchte ich eine einheitliche Antwortform, Board-Antworten ohne archivierte Karten und Filter,
damit meine Skripte ohne Sonderfälle auskommen.

## US-1: Karte direkt

- **Gegeben** die Aufgabe #7
- **Wenn** ich `GET /api/aufgaben/7` aufrufe
- **Dann** steht `nummer` auf oberster Ebene der Antwort, daneben `pfad` und `text`

## US-2: Archivierte nicht in den Spalten

- **Gegeben** Backlog mit #89 (archiviert) und #90
- **Wenn** ich `GET /api/boards/joinpuya` aufrufe
- **Dann** enthält Backlog nur #90

## US-3: Filtern

- **Gegeben** Backlog mit #90 (Klasse vorrang) und #93 (ohne Klasse)
- **Wenn** ich `GET /api/aufgaben?board=joinpuya&spalte=Backlog&klasse=vorrang` aufrufe
- **Dann** enthält `aufgaben` nur #90
