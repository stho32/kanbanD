# User Story R00182 — Aufgeklappte Abschnitte behalten den Tastaturfokus, wenn die Seite neu zeichnet

Als Mensch, der den Bericht „Kosten“ per Tastatur liest, während Agenten am Board arbeiten,
möchte ich, dass der Fokus auf der Klappe bleibt, auf der ich stehe,
damit ich nach einer fremden Änderung nicht von vorn durch die Seite tabben muss.

Herstellbar über die API: Board mit Kosteneinträgen der Rollen „entwickler“ und „planer“ in einer Währung; der fremde Schreibzugriff ist eine Titeländerung an einer Aufgabe über die API ([R00182](../R00182-klappen-behalten-den-tastaturfokus-beim-neuzeichnen.md)).

## US-1: Fokus auf der Klappe einer Rolle

- **Gegeben** der Bericht „Kosten“ mit zwei Rollen, die Klappe einer Rolle ist offen und trägt den Fokus
- **Wenn** ein fremder Schreibzugriff an einer Aufgabe eintrifft und die Seite neu zeichnet
- **Dann** steht der Fokus auf derselben Klappe (nicht auf der Seite), sie ist weiter offen; die Leertaste klappt sie zu

## US-2: Andere Klappen und geschlossene Klappe

- **Gegeben** der Fokus nacheinander auf der äußeren Klappe „Kosten je Rolle“, auf „Tabellenansicht“ im Burndown und auf einer geschlossenen Klappe einer Rolle
- **Wenn** jeweils ein fremder Schreibzugriff die Seite neu zeichnet
- **Dann** steht der Fokus jedes Mal auf derselben Klappe; die geschlossene bleibt geschlossen, die Leertaste öffnet sie

## US-3: Board-Wechsel

- **Gegeben** ein zweites Board und der Fokus auf dem Eintrag dieses Boards in der Board-Auswahl
- **Wenn** ich mit der Tastatur auf das zweite Board wechsle
- **Dann** liegt der Fokus danach auf einem Element der Seite, nicht auf der Seite selbst (`BODY`)
