# User Story R00063 — Kontextmenü am gescrollten Board

Als Mensch, der auf einem breiten Board arbeitet,
möchte ich, dass das Board beim Öffnen eines Kontextmenüs stehen bleibt,
damit Menü und angeklicktes Element beieinander liegen.

## US-1: Karte im quer gescrollten Board

- **Gegeben** ein Board mit mehr Spalten, als ins Fenster passen, quer und in einer Spalte längs gescrollt
- **Wenn** ich eine Karte rechts anklicke und über die Menüeinträge fahre
- **Dann** bleibt das Board quer und längs stehen und das Menü öffnet an der Karte

## US-2: Spaltenkopf

- **Gegeben** dasselbe gescrollte Board
- **Wenn** ich einen Spaltenkopf rechts anklicke
- **Dann** springt das Board nicht nach links und das Menü öffnet am Spaltenkopf

## US-3: Aufgabenliste

- **Gegeben** die Aufgabenliste ist weit nach unten gescrollt
- **Wenn** ich eine Zeile rechts anklicke
- **Dann** bleibt die Liste stehen und das Menü öffnet an der Zeile
