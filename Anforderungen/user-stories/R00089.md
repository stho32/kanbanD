# User Story R00089 — Gesamtzeit auf der Karte

Als Mensch, der das Board überblickt,
möchte ich an jeder Karte die gebuchte Gesamtzeit sehen,
damit ich ohne Öffnen erkenne, wo Zeit steckt.

## US-1: Summe auf der Karte

- **Gegeben** eine Aufgabe mit 1:00 von Stefan und 0:42 vom Entwickler-Agenten
- **Wenn** ich das Board ansehe
- **Dann** zeigt die Karte `Σ 1:42`, und der Tooltip nennt beide Anteile

## US-2: Laufender Timer zählt mit

- **Gegeben** eine Aufgabe mit 1:00 gebuchter Zeit
- **Wenn** ein Timer auf ihr läuft
- **Dann** wächst `Σ` jede Minute, ohne Reload

## US-3: Ohne Zeit kein Feld

- **Gegeben** eine Aufgabe ohne Zeiteinträge
- **Wenn** ich das Board ansehe
- **Dann** zeigt die Karte kein `Σ`
