# User Story R00057 — Wirkungen von Aufgaben auf die WBS

Als Mensch oder KI, der Arbeit an einer Anwendung plant,
möchte ich an einer Aufgabe festhalten, welche WBS-Knoten sie anlegt, überarbeitet oder entfernt,
damit Board und WBS ohne Abgleich zusammenpassen.

## US-1: Neuer Knoten aus einer Aufgabe

- **Gegeben** eine Aufgabe „Dialog Export bauen“ und die Anwendung `kd`
- **Wenn** ich ihr die Wirkung „anlegen: Dialog unter A0001“ gebe
- **Dann** steht in der WBS ein neuer roter Dialog, und die Karte zeigt seine ID

## US-2: Überarbeitung

- **Gegeben** ein grüner Dialog `D0002`
- **Wenn** eine Aufgabe die Wirkung „überarbeiten: D0002“ bekommt
- **Dann** sind `D0002` und seine Nachfahren rot, und die WBS-Sicht zeigt an `D0002` die Aufgabe

## US-3: Ausbau

- **Gegeben** eine Interaction `I0014`
- **Wenn** eine Aufgabe die Wirkung „entfernen: I0014“ bekommt
- **Dann** ist `I0014` verworfen und zählt nicht mehr im Stand
