# User Story R00139: Text auf einer eigenen Klassenfarbe trägt `--kd-text`

Als Mensch, der das Board im Dunkelthema ansieht,
möchte ich die Zeitsumme und das Datum auch auf einer Karte mit eigener Klassenfarbe lesen können,
damit ich weiß, wie lange an einer Aufgabe gearbeitet wurde und wann sie fällig ist.

Gegeben in allen Szenarien: das Board „entwicklung" bei 1280 px, über die API herstellbar; Aufgabe #1 in „Zu erledigen" mit 46 Minuten gebuchter Zeit und einer Fälligkeit, ihre Klasse trägt eine **eigene** Farbe `#ffffff` (keine der 16 Palettenfarben), sodass der Grund der Karte getönt ist (Merkmal `data-eigen`); Aufgabe #2 trägt die Palettenklasse `bug` (rot), sonst gleich. „Kontrast" ist das WCAG-Verhältnis der Schrift gegen den ersten deckenden Grund (R00107). „Beide Themen" heißt `data-theme=light` und `data-theme=dark`.

## US-1: Im Dunkelthema lese ich Zeitsumme und Datum auf einer eigenen Klassenfarbe

- **Gegeben** das Board im Dunkelthema, Aufgabe #1 mit eigener Klassenfarbe `#ffffff`, 46 Minuten gebucht und einer Fälligkeit
- **Wenn** ich die Zeile r3 der Karte ansehe
- **Dann** stehen „Σ 0:46" und das Datum in `--kd-text`, ihr Kontrast gegen den Kartengrund ist mindestens 4,5:1 (heute 2,571:1); dasselbe gilt im hellen Thema.

## US-2: Auf einer eigenen Klassenfarbe trägt auch die Herkunft `--kd-text`

- **Gegeben** die Aufgabe #1 aus US-1, ohne Herkunft (die Karte zeigt „ohne Herkunft")
- **Wenn** ich die Zeile r3 der Karte ansehe, in beiden Themen
- **Dann** steht „ohne Herkunft" in `--kd-text` und hält mindestens 4,5:1.

## US-3: Eine Karte mit Palettenfarbe bleibt, wie sie ist

- **Gegeben** die Karte #2 mit der Palettenklasse `bug` (rot), sonst gleich
- **Wenn** ich die Zeile r3 beider Karten in beiden Themen ansehe
- **Dann** trägt die Karte mit eigener Farbe überall `--kd-text`, die Karte mit Palettenfarbe weiter `--kd-muted`; die geprüfte Paarung `--kd-c-red` ↔ `--kd-muted` (R00107) ist unverändert, und ein erzwungenes `--kd-text` auf der Paletten-Karte macht diesen Fall rot.
