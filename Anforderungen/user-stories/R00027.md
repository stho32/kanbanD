# User Story R00027 — Mehrere Aufgaben auf einmal anlegen

Als Mensch mit einer Liste aus einem Protokoll
möchte ich sie auf einmal einfügen,
damit jede Zeile eine Aufgabe wird, ohne dass ich jede einzeln tippe.

## US-1: Liste in eine Spalte einfügen

- **Gegeben** ich bin „Stefan“ und habe „- Login\n- Logout\n- Passwort vergessen“ in der Zwischenablage
- **Wenn** ich in „Zu erledigen“ auf „+ Karte“ klicke und einfüge
- **Dann** stehen dort drei neue Karten in dieser Reihenfolge, entstanden in einem Commit

## US-2: Teilaufgaben einfügen

- **Gegeben** das Fenster von #1 ist offen
- **Wenn** ich drei Zeilen in „+ Teilaufgabe“ einfüge
- **Dann** hat #1 drei neue Teilaufgaben

## US-3: Aufgaben ohne Board einfügen

- **Gegeben** die Seite „Aufgaben“
- **Wenn** ich zwei Zeilen in „+ Aufgabe ohne Board“ einfüge
- **Dann** stehen zwei neue Aufgaben unter „ohne Board“
