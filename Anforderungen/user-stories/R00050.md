# User Story R00050 — Live-Ereignisse während eigener Anfragen

Als Mensch, der schnell Teilaufgaben tippt,
möchte ich, dass die Liste nicht springt, während meine Eingaben gesendet werden,
damit ich ohne Ablenkung weiterschreibe.

## US-1: Ruhige Liste

- **Gegeben** das Fenster einer Aufgabe ist offen
- **Wenn** ich zehn Teilaufgaben ohne Pause eingebe
- **Dann** wächst die Liste stetig und verliert zwischendurch keinen Eintrag
