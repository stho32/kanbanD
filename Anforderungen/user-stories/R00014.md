# User Story R00014 — Timer starten und stoppen

Als Mensch, der an einer Aufgabe arbeitet,
möchte ich mit einem Klick einen Timer starten und stoppen,
damit meine Zeit ohne Nachtragen erfasst wird.

## US-1: Starten

- **Gegeben** ich bin „Stefan“ und das Fenster von #1 ist offen
- **Wenn** ich „▶ Meinen Timer starten“ klicke
- **Dann** läuft mein Timer: die Karte zeigt die Dauer, die Kopfzeile „1 läuft“, die Datei eine Zeile mit `...`

## US-2: Fremden Timer stoppen

- **Gegeben** an #1 laufen die Timer von Stefan und Claude
- **Wenn** ich im Popover „1 läuft …“ Claudes Timer stoppe
- **Dann** hat Claudes Zeile ein Ende, mein Timer läuft weiter, und der Commit trägt meinen Namen

## US-3: Zweimal starten geht nicht

- **Gegeben** mein Timer läuft an #1
- **Wenn** ein Aufruf ihn noch einmal startet
- **Dann** wird er abgewiesen, und es entsteht keine zweite Zeile
