# User Story R00029 — Karte direkt bedienen

Als Mensch, der den ganzen Tag am Board arbeitet,
möchte ich Timer, Zuständigkeit und Titel direkt an der Karte ändern,
damit ich dafür nicht jedes Mal das Fenster öffne.

## US-1: Timer an der Karte

- **Gegeben** ich bin „Stefan“ und zeige auf #1
- **Wenn** ich ▶ klicke
- **Dann** läuft mein Timer an #1, ohne dass sich das Fenster öffnet

## US-2: Umbenennen an Ort und Stelle

- **Gegeben** #1 heißt „eins“
- **Wenn** ich doppelt auf den Titel klicke, „eins neu“ tippe und Enter drücke
- **Dann** heißt die Karte „eins neu“

## US-3: Fälligkeit per Knopf

- **Gegeben** das Fenster von #1 ist offen
- **Wenn** ich „morgen“ klicke
- **Dann** ist #1 morgen fällig
