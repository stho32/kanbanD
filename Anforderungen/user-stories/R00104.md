# User Story R00104 — Board-Name kann keine fremde Datei treffen

Als Betreiber eines Arbeitsordners, auf dem Agenten über die API arbeiten,
möchte ich, dass ein Board-Name nur ein Board im Board-Ordner meinen kann,
damit kein Agent — fehlerhaft oder böswillig — Dateien außerhalb des Boards liest, umschreibt oder eine Aufgabe zerstört.

Ausgangslage jeder Story: Arbeitsordner `w` mit Git, sauber; Board `fabrik` mit Spalten „In Arbeit“ und „Fertig“; Aufgabe #12 `aufgaben/0012-x.md` (id 12, title „x“, key `k12`) in „In Arbeit“; fremde Datei `fremd/boards/b.md` neben `w`. Agent `bot` schreibt über die API. „Nichts geändert“: kein neuer Commit, `git status --porcelain` leer, fremde Datei byte-gleich, #12 behält id, title und key.

## US-1: Erledigen mit Pfad statt Board-Namen wird abgewiesen

- **Gegeben** #12 in „In Arbeit“
- **Wenn** `bot` #12 erledigen will mit `board` `../../fremd/boards/b`, `../aufgaben/0012-x`, `..`, `.`, `a/b`, `./fabrik`, `fabrik\0` oder `""`
- **Dann** antwortet kanbanD jedes Mal 400, und nichts ist geändert

## US-2: Anlegen mit Pfad statt Board-Namen wird abgewiesen

- **Gegeben** derselbe Ordner
- **Wenn** `bot` eine Aufgabe „neu“ mit `board` `../../fremd/boards/b` (und mit jedem Wert aus US-1) anlegen will
- **Dann** antwortet kanbanD jedes Mal 400, es gibt keine Aufgabe #13, und nichts ist geändert

## US-3: Lesen mit kodiertem Pfad wird abgewiesen

- **Gegeben** derselbe Ordner
- **Wenn** jemand das Board `..%2F..%2Ffremd%2Fboards%2Fb` abruft oder die Aufgaben mit `?board=..%2F..%2Ffremd%2Fboards%2Fb` filtert
- **Dann** antwortet kanbanD 400, die Antwort enthält nichts aus der fremden Datei, und nichts ist geändert

## US-4: Gültiger Name, aber kein solches Board

- **Gegeben** derselbe Ordner
- **Wenn** `bot` mit dem Board-Namen aus 40 × `a` erledigt, anlegt oder liest
- **Dann** antwortet kanbanD 404, und nichts ist geändert; mit 41 × `a` oder `Fabrik` antwortet es 400

## US-5: Das richtige Board funktioniert wie bisher

- **Gegeben** #12 in „In Arbeit“
- **Wenn** `bot` #12 mit `board: "fabrik"` erledigt
- **Dann** antwortet kanbanD 200 „erledigt“, #12 steht in „Fertig“, und es gibt genau einen neuen Commit

## US-6: Handbenannte Board-Datei wird gemeldet, nicht verändert

- **Gegeben** zusätzlich eine von Hand angelegte Datei `boards/Alt_Board.md` mit gültigem Board-Inhalt
- **Wenn** der Zustand des Ordners abgerufen wird
- **Dann** steht `boards/Alt_Board.md` unter den defekten Dateien mit „Dateiname ist kein gültiger Board-Name — umbenennen“, nicht unter den Boards, und die Datei liegt unverändert unter ihrem Namen, ohne neuen Commit
