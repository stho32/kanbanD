# User Story R00084 — Zeitpunkte mit Zeitzone

Als Mensch oder Agent, der Zeit auf Karten bucht,
möchte ich, dass jeder Zeitpunkt seine Zone trägt,
damit Dauern auch über die Zeitumstellung stimmen.

## US-1: Eintrag über die Zeitumstellung

- **Gegeben** ein Zeiteintrag `2026-10-25 02:33+02:00` bis `2026-10-25 02:10+01:00`
- **Wenn** ich die Aufgabe öffne
- **Dann** zeigt die Zeitliste `02:33–02:10` und die Dauer `0:37`

## US-2: Neuer Timer trägt den Versatz

- **Gegeben** eine Aufgabe ohne laufenden Timer
- **Wenn** ich den Timer starte
- **Dann** steht in der Aufgabendatei ein Beginn mit `+01:00` (Winterzeit) und die Karte zählt ab `0:00:00`

## US-3: Altbestand bleibt lesbar

- **Gegeben** ein alter Eintrag `2026-10-18 09:00 · 2026-10-18 10:42` ohne Versatz
- **Wenn** ich die Aufgabe öffne
- **Dann** zeigt sie `1:42`, und die Zeile in der Datei bleibt unverändert
