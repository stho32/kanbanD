# User Story R00098 — Idempotentes Anlegen über einen Fremdschlüssel

Als Sensor der Wartungsfabrik, der täglich läuft,
möchte ich Befunde mit einem eigenen Schlüssel anlegen,
damit jeder Befund genau eine Karte hat, ohne dass ich Dubletten selbst erkennen muss.

## US-1: Erster Fund

- **Gegeben** es gibt keine Karte mit dem Schlüssel `shop/nc-304/lodash`
- **Wenn** ich eine Aufgabe mit diesem Schlüssel im Eingang anlege
- **Dann** entsteht eine Karte, und kanbanD antwortet mit 201

## US-2: Derselbe Fund am nächsten Tag

- **Gegeben** die Karte mit dem Schlüssel `shop/nc-304/lodash` liegt offen auf dem Board
- **Wenn** ich am nächsten Tag denselben Aufruf schicke
- **Dann** bekomme ich dieselbe Karte mit 200, es entsteht keine neue, und die Git-Geschichte bleibt unverändert

## US-3: Der Befund kehrt zurück

- **Gegeben** die Karte mit dem Schlüssel `shop/nc-304/lodash` wurde behoben und archiviert
- **Wenn** ich den Befund erneut anlege
- **Dann** liegt dieselbe Karte wieder oben im Eingang, trägt den Kommentar „Erneut gefunden“, und ihre alte Geschichte ist erhalten

## US-4: Schlüssel im Aufgabenfenster

- **Gegeben** eine Karte mit Schlüssel
- **Wenn** ich sie im Browser öffne
- **Dann** sehe ich die Zeile „Schlüssel“ mit dem Text und kann ihn nicht ändern
