# User Story R00072 — Wirkungsstand als Punkt auf der Karte

Als Mensch, der das Board überblickt,
möchte ich auf jeder Karte mit Wirkungen einen einzigen roten oder grünen Punkt sehen,
damit ich erkenne, ob ihre Arbeit in der WBS angekommen ist, ohne dass Chips Platz wegnehmen.

## US-1: Gebaut ist grün

- **Gegeben** eine Karte mit der vermerkten Wirkung „rework I0014“, I0014 ist grün
- **Wenn** ich das Board ansehe
- **Dann** zeigt die Karte unten einen grünen Punkt, dessen Tooltip „↻ kd:I0014 überarbeiten“ mit Stand nennt, und keine Wirkungs-Chips

## US-2: Eine offene Wirkung macht rot

- **Gegeben** eine Karte mit „rework I0014“ (grün) und „remove I0047“ (nicht verworfen)
- **Wenn** ich das Board ansehe
- **Dann** ist der Punkt rot; schalte ich „remove I0047“ im Aufgabenfenster ein, wird er grün
