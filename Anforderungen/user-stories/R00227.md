# User Story R00227: Die Lizenz der eingebetteten Schriften wird mit ausgeliefert

Als Betreiber `sh`, der das Programm kanbanD auf weiteren Rechnern installiert und weitergibt,
möchte ich, dass das Programm die Lizenz der Schriften mitliefert, die es einbettet,
damit ich die Schriften nach den Bedingungen der SIL Open Font License weitergebe, ohne die Datei selbst aus dem Repository beilegen zu müssen.

Herstellbar: kanbanD auf einem Wegwerf-Ordner starten (Ausgangslage von [R00227](../R00227-behebung-ofl-lizenz-der-schriften-ausliefern.md), Abschnitt „Akzeptanzkriterien“), Abruf per HTTP.

## US-1: Lizenz der Schriften abrufen (Fehlerszenario von heute)

- **Gegeben** kanbanD läuft auf einem Wegwerf-Ordner
- **Wenn** ich `GET /web/fonts/LICENSE-OFL.txt` aufrufe
- **Dann** bekomme ich 200 mit `text/plain; charset=utf-8`. Der Text beginnt mit „Copyright 2019 IBM Corp.“ und enthält „SIL OPEN FONT LICENSE Version 1.1“. Heute: 404 „nicht gefunden“.

## US-2: Jede Datei unter `web/fonts/` und `web/vendor/` kommt mit (Grenze)

- **Gegeben** kanbanD läuft, und unter `web/fonts/` und `web/vendor/` liegen zusammen 8 Dateien
- **Wenn** ich jede dieser Dateien unter `/web/<ordner>/<name>` abrufe
- **Dann** antwortet jede mit 200 und dem Typ ihrer Endung (`.woff2` `font/woff2`, `.js` `text/javascript; charset=utf-8`, `.txt` `text/plain; charset=utf-8`); keine antwortet mit 404.

## US-3: Prism bleibt unverändert (Gegenprobe)

- **Gegeben** kanbanD läuft
- **Wenn** ich `GET /web/vendor/LICENSE-prism.txt` aufrufe
- **Dann** bekomme ich wie bisher 200 mit `text/plain; charset=utf-8` und den Text, der mit „MIT LICENSE“ beginnt.
