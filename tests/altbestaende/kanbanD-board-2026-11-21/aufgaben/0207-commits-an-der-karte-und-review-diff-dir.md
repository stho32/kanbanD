Die Agents können die automatisch hinterlegen (für Menschen kann es gerne ebenfalls ein UI Interface geben, aber ich gehe davon aus, dass sie sie nicht wirklich verwenden können). Es soll auch einen Review-Knopf geben, der dann alle für eine KanbanD-Karte gemachten Änderungen in einem Diff-Fenster anzeigt, d.h. alle Dateien und alle Änderungen darin. Der Code soll angezeigt werden, Syntax Highlighting und ein Standard Diff View, so wie man es kennt. Es muss in dieser Version keine weiteren Funktionen geben. Es soll nur möglich sein, die Commits einzeln oder alle Änderungen der Karte als ein gemeinsames Diff nachzuvollziehen und zwar direkt aus dem Kanban-Board.“
