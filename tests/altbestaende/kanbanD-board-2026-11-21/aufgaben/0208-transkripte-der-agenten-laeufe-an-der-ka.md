**Herkunft:** Betreiber als Product Owner, 2026-11-19 (wörtlich): „Aus der gleichen Richtung: Es wäre schön, wenn man einen Weg hätte das Transkript zu hinterlegen und ein Review für das Transkript der Agenten-Läufe machen zu können. Die API müsste auch hier einen Endpunkt geben, so ähnlich wie die Kosten hinterlegt werden können soll auch so ein Lauf einfach hinterlegt werden können.“
