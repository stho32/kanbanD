# Worum es geht

kanbanD ist ein Kanban-Board, das ein Ordner ist: je Aufgabe und je Board eine Markdown-Datei, jede Aktion ein Commit. Menschen arbeiten im Browser, KI-Agenten über die API oder direkt an den Dateien, und jede Änderung erscheint sofort als Live-Ereignis in allen offenen Sichten. Eine Aufgabe liest und bearbeitet man im Aufgabenfenster, auf dem Desktop wie im schmalen Layout am Handy. Damit Live nicht stört, muss die Oberfläche beim Neuzeichnen Leseposition und angefangene Eingabe der Person stehen lassen.
