kanbanD · API für Agenten und Skripte
zur Oberfläche

Alles, was die Oberfläche kann, kann auch ein Agent.

Jeder schreibende Aufruf nennt im Header X-KanbanD-Wer: <kürzel> die handelnde Person aus kanbanD.md; kanbanD committet unter ihrem Namen. Lesen braucht keine Identität. Antworten sind JSON, Fehler {"fehler": "…"}.

curl -X POST http://localhost:7420/api/aufgaben -H 'X-KanbanD-Wer: cl' -H 'Content-Type: application/json' -d '{"titel":"Dateiwächter","board":"entwicklung"}'
