# Git

## Verantwortung

Git committet genau die Pfade einer Aktion mit der handelnden Person als Autor.

## Schnittstellen

- eingehend: `git::committen(wurzel, pfade, autor, nachricht)`
- ausgehend: Kindprozess `git -C <ordner>`, Autor `<kürzel>@kanbanD`

## Notizen / Quellen

- Andere Änderungen im Arbeitsbaum oder Index bleiben unberührt; ohne Änderung kein Commit.
- nachgeführt 2026-11-11 nach R00128 (#35): Löschen committet einen **entfernten** Pfad — `git::committen` nimmt auch gelöschte, `git` bekannte Pfade mit (`git add -A`); der Löschweg ist ein **Entfernen-Schritt** (`Schritt::Entfernen`) in `Kanban::aktion` (`src/dienst/mod.rs`), kein eigener Weg daneben; alle Pfade beider Arten werden vor dem ersten Schritt geprüft.
- nachgeführt 2026-11-11 nach R00141 (#36, ADR-0024): das endgültige Löschen einer Aufgabe entfernt Aufgabendatei, ihre Zeilen aus **allen** Board-Dateien und ihren Anhangsordner in **einem** Commit (`Kanban::endgueltig_loeschen`). `git::staende` überspringt Commits, in denen die Datei **gelöscht** ist (`src/git.rs:61–62`) — der Karten-Verlauf (R00123, ADR-0021) endet damit beim Löschen; die Karte bleibt über `git show`/`git log -- <pfad>` rekonstruierbar (Git ist der Papierkorb).
